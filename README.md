## First launch
- **Windows:** if you see "Windows protected your PC", choose **More info → Run anyway**.
- **Mac:** if Mockfy cannot be opened, right-click it in Applications and choose **Open**.
- **Android:** allow installing apps from your browser when asked.

Sign in with **Sign in with your browser**: your browser opens, you sign in with Google or Telegram, and you come back to the app.

This repository holds the desktop app's source (an Electron window on mockfy.uz) and builds the installers with GitHub Actions; see [BUILDING.md](BUILDING.md).
